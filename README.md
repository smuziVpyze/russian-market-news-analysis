# Анализ влияния финансовых новостей на российский фондовый рынок

**NLP + Time Series Analysis | 2022–2024**

---

## Что хотели сделать

Проверить простую гипотезу: **влияет ли тональность финансовых новостей на движение российского фондового рынка?**

Конкретно — можно ли по новостям предсказать, вырастут или упадут акции завтра.

---

## Что сделали

За основу взяли готовый датасет **RussianFinancialNews** с Kaggle — 91,955 русскоязычных финансовых новостей из Finam, RBC, BCS, SmartLab и Telegram-каналов. После фильтрации по периоду и длине текста осталось **61,398 новостей** за 2022–2024. Дополнительно загрузили **дневные котировки** недостающих инструментов через MOEX ISS API. Разметили каждую новость по тональности (позитивная / нейтральная / негативная) с помощью русскоязычной BERT-модели. Обучили несколько моделей прогнозирования — от простой логистической регрессии до LSTM-нейросети.

## Что получилось

### Корреляционный анализ
Тональность новостей **статистически значимо коррелирует** с доходностью акций в тот же день — для всех шести инструментов (p < 0.05). Коэффициент Pearson от 0.097 (GAZP) до 0.169 (PLZL). При этом тест Грейнджера показал отсутствие причинно-следственной связи с задержкой — рынок отыгрывает новости мгновенно.

### Модели прогнозирования

| Модель | Средний ROC-AUC |
|--------|----------------|
| Baseline (всегда рост) | 0.500 |
| Logistic Regression | 0.498–0.511 |
| Random Forest | 0.517 |
| XGBoost | 0.504 |
| **LSTM** | **0.606** |

Лучший результат — **LSTM для GAZP: ROC-AUC = 0.655**.

### Ключевые выводы

1. Сентимент новостей связан с рынком **в тот же день**, но не предсказывает следующий день
2. **LSTM превосходит** классические методы ML благодаря учёту временных зависимостей
3. **Общий новостной фон** информативнее, чем новости о конкретной компании
4. Результат согласуется с **гипотезой эффективного рынка** — информация отыгрывается мгновенно
